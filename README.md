## 🗺️ What is MEDICORE?

**MEDICORE** is a next-generation decentralized pharmaceutical traceability platform that combines **Ethereum smart contracts**, an **off-chain high-frequency telemetry & anomaly sentinel engine**, and a **multi-role Web3 application**.

Every drug batch is minted as an immutable on-chain asset, reviewed by certified Quality Officers, physically tracked using real-time GPS telemetry, and handed over between supply chain custody tiers using **zero-knowledge cryptographic delivery secrets**.

<details open>
<summary><b>🔴 The Global Counterfeit Crisis</b></summary>

<br/>

> The World Health Organization (WHO) estimates that **over $200 billion** in counterfeit, contaminated, and diverted pharmaceuticals are distributed annually. In developing regions, up to 1 in 10 medical products fail quality standards or are outright fraudulent.

| Pain Point | Conventional Supply Chains | MEDICORE Solution |
|---|---|---|
| 🗂️ **Data Silos** | Disconnected internal ERP databases | Single, shared, immutable blockchain ledger |
| 🥷 **Diversion & Black-Market** | Unauthorized units created with fake paperwork | **Strict Mathematical Quantity Conservation** ($Q_{init} = Q_{rem} + Q_{trans}$) |
| 🚚 **Transit Theft & Fake Handoff** | Drivers falsify paper delivery receipts | **Cryptographic Delivery Codes** (Keccak256 hash locked) |
| 🌡️ **Cold-Chain Spoilage** | Temperature excursions undetected during transit | **Automated IoT Sensor Telemetry & Smart Quarantine** |
| 🔍 **Zero Consumer Trust** | Patients cannot verify medicine at counter | **Public QR Zero-Wallet Verification** |

</details>

                     │                              │

## 🔐 Key Architectural Guarantees

### 1. 🧮 Mathematical Quantity Conservation
Centralized databases allow arbitrary inventory duplication. MEDICORE enforces strict mathematical invariance directly in the EVM:

$$\sum Q_{\text{minted}} = Q_{\text{remaining}} + Q_{\text{transferred}} + Q_{\text{quarantined}}$$

Any attempt to transfer more units than available reverts the transaction with `"Insufficient stock"`.

### 2. 🔑 Zero-Knowledge Cryptographic Handoff
Physical possession is decoupled from on-chain ownership:
$$\text{Given secret code } C, \quad \mathcal{H} = \text{keccak256}(C)$$
Only $\mathcal{H}$ is stored in the contract. The receiving wholesaler must provide $C$ to claim inventory. Transporters cannot forge delivery.

### 3. 🚨 Sentinel Anomaly Engine
Off-chain telemetry monitors scan attempts in real-time. If 3 consecutive incorrect verification codes are submitted for a shipment, the backend alerts the Regulator dashboard with a `SUSPICIOUS_QR` incident, mitigating brute-force attacks.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js** v18+
- **MetaMask** browser extension

### 1 · Clone Repository
```bash
git clone https://github.com/bhumiadi23/MEDICORE.git
cd MEDICORE
```

### 2 · Start Blockchain & Seed State
```bash
# Terminal 1: Start local node
cd blockchain
npm install
npx hardhat node

# Terminal 2: Deploy and seed demo data
cd blockchain
npx hardhat run scripts/deploy.js --network localhost
npx hardhat run scripts/seed.js --network localhost
```

### 3 · Start Telemetry Sentinel Backend
```bash
# Terminal 3: Start Express / SQLite backend
cd backend
npm install
npm start
# → Listening on port 3001
```

### 4 · Launch Frontend
```bash
# Terminal 4: Start Vite development server
cd frontend
npm install
npm run dev
# → Access at http://localhost:5173
```
